# 企业对账与结算管理系统企业能力

## 领域覆盖

- **结算主体**：维护客户、供应商、平台、账户和结算周期
- **结算规则**：配置费率、税率、账期、舍入和容差规则
- **交易归集**：导入订单、退款、费用、调整和资金流水
- **自动对账**：按业务键、金额、日期和组合规则执行匹配
- **差异处理**：分派长短款、重复、缺失和跨期差异并复核
- **结算单**：生成明细、汇总、调整项和版本化结算单
- **对方确认**：支持线上确认、异议、证据和重开流程
- **开票付款**：连接发票、付款计划、银行回单和核销结果
- **结算审计**：保留导入批次、规则版本、差异和审批证据

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 治理驾驶舱按组织与账期汇总在途、逾期、临期、证据缺口、同步失败和办结率；
- 批量提交与批量审批限制在 100 条以内并使用单事务，任一记录非法时整体回滚；
- 管理员可冻结或重新开放组织账期，冻结状态由服务端拦截所有关键业务变更；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业对账与结算管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `ERP`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
